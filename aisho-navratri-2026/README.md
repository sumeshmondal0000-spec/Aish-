# Aisho Navratri 2026 Campaign

Temporary WordPress plugin for:

- Homepage festive colour treatment, Dandiya/Garba details and campaign banner
- Interactive **Find Your Garba Partner** page at `/find-your-garba-partner/`
- Automatic expiry at **24 October 2026, 11:59 PM Asia/Kolkata**
- Automatic redirect of the campaign URL to the homepage after expiry
- Original Aisho theme remains untouched

## Install

1. Download the `aisho-navratri-2026` folder as a ZIP.
2. In WordPress go to Plugins → Add New → Upload Plugin.
3. Activate **Aisho Navratri 2026 Campaign**.
4. Clear WordPress/CDN cache.
5. Verify the homepage banner and `/find-your-garba-partner/`.

Deactivate or delete the plugin at any time to remove the campaign immediately.
